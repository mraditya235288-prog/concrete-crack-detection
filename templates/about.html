COLLEGE PROJECT

Crack Detection in Concrete Structures

Computer vision based identification and measurement of visible concrete cracks.

OBJECTIVE

What the system does

Automatically identify visible cracks in concrete structures using the provided OpenCV image-processing pipeline and provide estimated crack dimensions and severity classification.

CURRENT IMPLEMENTATION

Two real image inputs

The website accepts normal JPG/JPEG/PNG uploads and real photographs captured directly from a laptop, desktop or mobile browser camera. Both input methods use the same Flask → OpenCV processing function.
